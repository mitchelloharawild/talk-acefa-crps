Mean Absolute Error (MAE)

MAE compares forecast means with observed values.

\[ \text{MAE}(\hat{y}, y) = \frac{1}{h} \sum_{t=T+1}^{T+h} \left| \hat{y}_t - y_t \right| \]

Where:

  • \(\hat{y}_t\): forecast mean at time \(t\)
  • \(y_t\): observed value at time \(t\)
  • \(h\): forecast horizon (number of forecasts)

Continuous Ranked Probability Score (CRPS)

CRPS compares the forecast distribution with observed values.

\[\text{CRPS}(F, y) = \int_{-\infty}^{\infty} \left( F(x) - \mathbf{1}\{x \geq y\} \right)^2 dx\]

Where:

  • \(F(x)\): forecast cumulative distribution function at value \(x\)
  • \(y\): observed value
  • \(\mathbf{1}\{y \geq x\}\): indicator function (equals 1 if \(x \geq y\), 0 otherwise)

Continuous Ranked Probability Score (CRPS)

CRPS is ideal to evaluate forecast accuracy

It rewards forecasts that are accurate and precise.

It penalises forecasts that are:

  • Inaccurate - far from the observed value
  • Imprecise - wide intervals
  • Unreliable - narrow intervals (when incorrect)
